# Web3Forms Setup Guide - Palak Developers

## Quick Setup (5 minutes)

### Step 1: Create Your Web3Forms Access Key

1. **Visit:** https://web3forms.com
2. **Click:** "Create your Access Key" button
3. **Enter your email:**
   ```
   YOUR_EMAIL@gmail.com (or any email you use)
   ```
4. **Enter destination email:**
   ```
   info@palakdevelopers.ke
   ```
5. **Verify** your email (check inbox for verification link)
6. **Copy** the access key (looks like: `a1b2c3d4-5678-90ab-cdef-1234567890ab`)

---

### Step 2: Add Access Key to Website

Once you have your access key, I'll add it to the form handler.

**Just reply with your access key and I'll configure it immediately!**
